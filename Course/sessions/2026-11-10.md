# Session 2026-11-10 - From the handoff to a Lesson 1 draft

**Who:**  Jason, Claude (Opus 5.5).  **Where:**  Jason's Windows computer at
school, in VS Code, part of it remoted in from his Mac.

## Where we started

The repository was a fresh copy of the team's robot code, with
`Course/HANDOFF.md` and no course plan.  Claude's memory for this project was
empty.  Jason:  *"we got a handoff here I'd like to pick up.  Let's lay the
foundation for building a new course plan from scratch here."*

## How it went

1. Claude read the handoff, installed the memory notes from
   `OODP_Lessons/meta/claude-memory/`, and ran a structured kickoff.
2. Claude drafted six course goals and a full scope and sequence built around
   functional programming, the paradigm in the course title.  Jason turned it
   down:  *"Please don't put words in my mouth ;)  Your 6 goals are way off the
   mark right from the start."*
3. Jason gave the real context in a stream of consciousness:  Strategy, State,
   Facade, and extensions as a Decorator, ending in a presentation to the FTC
   community at the fall Kickoff.  Then the title:  *"the Course Title is the
   equivalent of a biological appendix."*
4. The sequence's opening came out a piece at a time:  the concrete model
   first, then dumb components, then `IControlStrategy`.  Claude found the
   canonical example in the code (`DoublyLimitedMotor` in `CascadeArm`), and
   Jason confirmed it.
5. Jason set the rails:  *"we make the road by walking"*.  Claude rewrote
   `Course/README.md` from his words alone.
6. Lesson starters became submodules, like OODP's.  The first Lesson 1 starter
   kept all four robots; Jason cut it to a base bot with only what the lesson
   needs.  Telemetry became the course's `Console.WriteLine`.
7. Jason couldn't find the starter in VS Code.  Fixing that led to the layout:
   the robot code snapshot moved into `ReferenceCopy/`, so no Gradle project
   sits inside another.
8. Publishing:  the submodule registered with no remote, `gh` got logged in,
   and both repositories went up public under CC BY-NC-SA 4.0.  A test clone
   failed on Windows' path-length limit, which led to the `core.longpaths` step
   in the clone instructions.
9. Lesson 1 planning, by dialogue:  a robot on the table and *"What the hell
   is this thing?"*, the configuration as the bridge, `hardwareMap` traced down
   and back up, an unrecorded discussion, and polymorphism held for day 5.
   `Robot` now requires a drive train.
10. Claude drafted the Lesson 1 plan.  Jason pointed at
    `ClaudeWritingProject` for the style guide, and the draft was checked
    against it.  He asked for these session notes.
11. Jason marked up the plan in place:  *"Lets work from this for now.  And
    we'll come back to it once we have some hard copy lessons down."*  Claude
    adapted OODP's chapter process and build script, drafted Chapter 1, and
    built it into Word and Canvas pages for four meetings.
12. Jason approved the chapter:  *"this looks good, let's move to the print
    version~"*  Claude added `finish_book.ps1` (OODP's, with the Field Guide's
    locked-PDF fix) and a `preview_pages.ps1` to look at the pages, and built
    a 14-page book PDF with four meeting handouts.

  by Jason.  Changed:  memory note `context-before-drafting`; every decision
  since is quoted from him before anything is built on it.

  Java 8, the build failed, and the "exit 0" came from a trailing `echo`.
  Caught by Claude on the next build.  Changed:  the right JDK is in
  PLANNING_NOTES, and exit codes now come from Gradle itself.
- **Miscounted lines in a `sed` edit** of `MechComponent`, duplicating one
  line and dropping a tag.  Caught by Claude reading the result.  Changed:
  whole files get rewritten instead of patched by line number.
- **Kept too much in the first starter.**  Caught by Jason.  Changed:  starters
  carry only what the lesson needs (PLANNING_NOTES).
- **Left the starter as an uncommitted nested repository,** invisible to
  Jason's tools.  Caught by Jason.  Changed:  every starter becomes a
  submodule right away (`Course/SUBMODULES.md`).
- **Checked prose against OODP's copy of the style guide,** which was 71 lines
  behind the canonical one in `ClaudeWritingProject`.  Caught by Jason.
  Changed:  this course points at `ClaudeWritingProject/style-guide/`, and the
  OODP copy was brought up to date.

## What we learned about the process

- A kickoff that settles logistics hasn't settled purpose.  Ask what the course
  is for, in Jason's words, before drafting.
- Planning by short exchanges works:  one question, Jason's answer quoted into
  the notes, Claude's reading marked as a reading, then the next question.
- Quoted errors get checked against the real code before they go in.  The
  misspelled-label failure turned out to be an `IllegalArgumentException` in
  the SDK.
- Test the path a student or another computer will take.  The fresh clone found
  the Windows path problem; a local check never would have.
